## 🌟 ฟีเจอร์หลัก (Features)
- 🔍 **Search City:** ค้นหาสภาพอากาศได้ทุกเมืองทั่วโลก
- 🌡️ **Real-time Data:** ดึงข้อมูลอุณหภูมิ, สภาพอากาศ, ความชื้น จาก OpenWeatherMap API
- 🖼️ **Dynamic Background:** พื้นหลังเปลี่ยนอัตโนมัติทุกๆ 5 วินาที
- 📱 **Responsive Design:** รองรับการใช้งานทั้งบนคอมพิวเตอร์และมือถือ

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
- **HTML5** - โครงสร้างหน้าเว็บ
- **CSS3** - ตกแต่งความสวยงาม (Flexbox, CSS Transitions)
- **JavaScript (ES6+)** - จัดการ Logic, Fetch API, DOM Manipulation
- **OpenWeatherMap API** - แหล่งข้อมูลสภาพอากาศ
